# Security Policy

The Nexora Voice team takes security and user privacy seriously. Because Nexora Voice captures microphone audio and simulates keystroke injection system-wide, preserving system integrity and local isolation is paramount.

---

## Supported Versions

Only the latest release of Nexora Voice is actively supported for security updates:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

---

## Reporting a Vulnerability

If you discover a security vulnerability or potential issue within Nexora Voice, please **do not open a public issue**. Instead, submit a report privately:

1. **GitHub Private Vulnerability Reporting**: Use the [Security Advisory](https://github.com/gautamcoder235/Nexora-Voice/security/advisories/new) tab on the repository.
2. **Direct Email**: Alternatively, contact the maintainer directly at `gautam.code@pm.me` (or via GitHub profile contact).

### What to Include in Your Report
* Description of the vulnerability and its potential impact.
* Step-by-step reproduction instructions or proof-of-concept.
* Operating system and hardware details.
* Any suggested mitigations or patches.

### Our Response Process
* We will acknowledge receipt of your report within **48 hours**.
* We will investigate and provide an estimated timeline for a patch.
* Once a fix is verified, a release will be published and credit will be acknowledged in the release notes (unless anonymity is requested).
